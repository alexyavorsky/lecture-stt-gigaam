# GigaAM MLX — гайд

## Переменные

```python
video_path = "lecture.mp4"
```

Путь к исходному видео.

```python
audio_path = "lecture_audio.mp3"
```

Путь и имя файла, куда будет сохранено извлечённое аудио.

## Где результат

Итоговая транскрипция сохраняется сюда:

```text
lecture_transcript.txt
```

Файл создаётся **в той же папке, из которой запускается скрипт**.

Аудио после конвертации:

```text
lecture_audio.mp3
```

также сохраняется по пути, указанному в `audio_path`.

## Что нужно изменить

Обычно достаточно изменить только:

```python
video_path = "lecture.mp4"
audio_path = "lecture_audio.mp3"
```

При необходимости можно изменить размер частей:

```python
max_chunk_sec=20
```
